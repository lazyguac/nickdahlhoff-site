Personal Knowledge Hub

Personal Knowledge Hub is Nick Dahlhoff’s collection of private tools for organizing his own information and running personal workflows. It is not offered as a public service and has no public sign-up.

The encrypted backup feature uses Google Drive to preserve files selected by the owner. Backup file contents and names are encrypted on the owner’s computer before they are sent to Google Drive. The recovery password is held separately by the owner, with a copy in a password manager accessible from another device. Google can still see storage metadata such as file sizes and upload times.

Other personal integrations use separately authorized Gmail and Calendar permissions. Each Google authorization screen identifies the access being requested.

Privacy information · Use of these tools

Privacy information

Google account access is used to carry out workflows the owner authorizes. The backup connection requests access to Drive files created by, or opened with, the app. It uses that access to create encrypted backup data, check available storage, and restore backups.

The backup service’s dedicated credentials and recovery password are stored outside the folders selected for backup. Google stores encrypted backup data. Local monitoring records contain operational status and recovery references.

The Gmail and Calendar integrations process account information through the tools the owner chooses to operate them, including AI assistants where authorized. Information returned by these integrations may appear in the owner’s assistant conversations, where the provider’s policies and the owner’s settings govern handling and retention. This page does not grant those tools additional permissions.

The owner can revoke Google access in Google Account settings. Revocation stops future access through that authorization; it does not erase existing backups. Backup deletion is a separate owner decision.
